# ✅ To-Do List Project (Python + Flask)

## Overview
This is a simple To-Do List web application built with Python, Flask, and SQLite. It allows users to add, manage, and organize tasks through a clean, responsive web interface.

## Features
- ➕ Add new tasks
- ✔️ Mark tasks as completed
- ❌ Delete tasks
- 📋 View all tasks in a list
- 🗄️ Persistent storage via SQLite
- 🌐 Web-based interface styled with Tailwind CSS

## Tech Stack
- **Backend:** Flask (Python)
- **Frontend:** HTML, Tailwind CSS
- **Database:** SQLite

## Installation & Setup
1. Clone the repository.
   ```bash
   git clone https://github.com/Zepyhr-cell/to_do_app.git
   ```
3. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Run the application:
   ```bash
   python app.py
   ```

## Usage
- Open the application in your browser.
- Use the input form to add new tasks.
- Click to mark tasks as complete or remove them from your list.
- All data is saved automatically to the database for future sessions.
